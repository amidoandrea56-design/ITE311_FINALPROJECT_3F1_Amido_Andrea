# Vue Grocery List

**Student Name:** Andrea Amido
**Course and Section:** BSIT 3-F1

## Project Description
Vue Grocery List is a simple web application where users can add grocery items with their prices and remove items from the list. The app also shows the total price of all items and an error message when the input is invalid.

## Technologies Used
- Laravel
- Vue.js 3
- Vite
- JavaScript
- HTML and CSS
